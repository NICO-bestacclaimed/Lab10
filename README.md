# Lab10 Gestión de productos

Aplicación React creada con Vite, Tailwind CSS y componentes de shadcn/ui.

## Requisitos

Node.js 22.12 o superior y npm.

## Ejecutar

```powershell
npm install
npm start
```

La aplicación se abre en http://127.0.0.1:5174/.

```powershell
npm run build
npm run preview
```
